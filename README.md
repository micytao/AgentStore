# Agent Store (prototype)

Internal catalog of governed AI agents. Browse by department, launch a task, and either work interactively (Collaborative / C) or approve a draft (Autonomous / A).

This is a thin OpenShift-ready prototype. It is not the six-phase platform.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). There is no login; you are `demo-user`.

### C — Collaborative Mode (Engineering)

1. Catalog → Engineering → **Claude Code** → Launch.
2. Wait until status is Running, then type in the terminal.
3. Stop session. The task appears under **My Tasks**.

Without `OPENSHELL_GATEWAY_URL`, Collaborative Mode uses a simulated session (clearly labeled). With the gateway set and the `openshell` CLI on PATH, Engineering listings provision a real sandbox.

### A — Autonomous Mode (Support / Security / Data)

1. Catalog → Customer Support → **Draft a ticket reply**.
2. Goal example: `Draft a reply to INC-1042 about a billing outage`.
3. Wait for **AwaitingApproval**, read the draft, Approve or Reject.

By default the draft text is simulated (canned per-listing text). Add a real
model provider in **Admin → Providers** (see below) to have that draft
generated by an actual model call instead.

### Admin console

The **Admin** tab (toggle Admin mode in the sidebar) has three tabs backed by
real, functional integrations, not just config forms:

- **Providers** — add a real API key for Anthropic, OpenAI, an OpenAI-compatible
  endpoint, or Gemini. "Test connection" makes a real call to the provider's
  models endpoint. Mark one provider active; it's then used to generate real
  Autonomous-mode drafts (see `apps/web/src/server/drafting.ts`), with a
  fallback to the simulated text if no provider is configured or a call fails.
- **MCP** — register a real MCP server (stdio command, or a Streamable
  HTTP/SSE URL) and connect to it using `@modelcontextprotocol/sdk`. Enable
  individual tools the active provider is allowed to call while drafting.
  `stdio` servers spawn a local command you specify — only connect servers
  you trust.
- **Secrets** — an encrypted local vault (also used internally by Providers
  and MCP to store API keys and auth tokens) for the two engine-related
  tokens `OPENSHELL_GATEWAY_TOKEN` and `GIT_PAT`. A value saved here
  overrides the matching environment variable for the life of the server
  process. This is a local, prototype-grade vault — not a substitute for a
  real secrets manager (see `docs/DEFERRED.md`).

## Configuration

| Variable | Purpose |
| --- | --- |
| `OPENSHELL_GATEWAY_URL` | If set, Engineering `work-with-me` listings use the OpenShell adapter |
| `OPENSHELL_CREATE_ARGS` | Extra args inserted into `openshell sandbox create` |
| `CATALOG_DIR` | Override path to `catalog/listings` |
| `SECRETS_ENCRYPTION_KEY` | Passphrase used to derive the local secrets-vault encryption key. If unset, a key is auto-generated and stored locally — set this explicitly for anything beyond local/demo use |
| `SECRETS_DATA_DIR` | Override path to the vault/provider/MCP config directory (defaults to `.data`) |

Admin-configured providers, MCP servers, and secrets call out to real
external endpoints (model provider APIs, MCP server URLs) — outbound network
access from the server is required for those features to work, the same as
for `OPENSHELL_GATEWAY_URL`.

## Layout

- `apps/web` — Next.js storefront + BFF
  - `src/server/secrets.ts` — encrypted local vault (AES-256-GCM)
  - `src/server/providers.ts` — model provider registry + real chat/model-list calls
  - `src/server/mcp.ts` — real MCP client (`@modelcontextprotocol/sdk`)
  - `src/server/drafting.ts` — real Autonomous-mode draft generation, with a simulated fallback
- `packages/shared` — Listing / Task types and `EngineAdapter`
- `packages/engine-fake` — Simulated engine (all business listings; Engineering when no gateway)
- `packages/engine-openshell` — CLI-backed Engine 1 adapter
- `catalog/listings` — YAML catalog
- `deploy/openshift` — Eval Helm values and app manifests
- `docs/DEMO.md` / `docs/DEFERRED.md`
